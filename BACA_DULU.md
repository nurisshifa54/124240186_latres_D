Cara membuat project lengkap (cukup sekali):

1. Ekstrak zip ini. Folder hasilnya: 124240186_latres_D
2. Windows: klik dua kali setup.bat
   Mac/Linux: jalankan bash setup.sh di folder ini
3. Tunggu sampai muncul SELESAI.
4. Buka folder 124240186_latres_D di VS Code, lalu jalankan flutter run.

Setelah itu folder isi_project hilang sendiri dan project sudah utuh (lib, android, pubspec, assets, README).
Untuk upload ke GitHub: nama repo nim_latres_D, jangan di-zip.
